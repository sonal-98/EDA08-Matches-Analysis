# Matches Analysis

## Project Overview

An Exploratory Data Analysis project using IPL match data to understand team performance, match outcomes, toss decisions, player performance, and city- and venue-level patterns.

## Objectives
Analyze match and season trends.
Compare team performance and wins.
Study toss decisions and match outcomes.
Identify strong player performances.
Analyze venue-level match patterns.
Compare team performance across seasons.

## Dataset
IPL match and detailed match data containing seasons, city, venue, teams, venues, toss decisions, match results and player-related information.

## Analysis Performed
Data loading and preprocessing.
Missing-value and consistency checks.
Team and venue standardization.
Season-wise match analysis.
Toss winner and decision analysis.
Team win analysis.
Player performance analysis.
Venue analysis.
Comparative seasonal analysis.
Visualizations

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Kaggle Notebook

## Key Skills

Sports Analytics, GroupBy, Aggregation, Comparative Analysis, Data Visualization and EDA.
